# agilab
AGI Lab — эксперименты по самоисправлению ИИ через внешний фидбек

В этом репозитории я выкладываю логи и код своих экспериментов с локальными моделями (Qwen 3 4B). Основная идея: модель генерирует решение (код), мы проверяем его выполнение и возвращаем ошибку, модель исправляет. Так мы пытаемся воспроизвести цикл «гипотеза → эксперимент → рефлексия» на ограниченном железе.
